# Csharp Doolhof
Dit is een C# console-applicatie waarin de gebruiker een bestand kan laden.
Dit bestand wordt dan gecontroleerd, en dan kan de gebruiker het spel spelen met de WASD-knoppen.

## Hoe te gebruiken
Zet een doolhof bestand in de juiste directory. Dit is /bin/debug als je in debug mode doet, of /bin/release als je in release mode doet.
Het moet een .txt bestand zijn, met een S voor start, een K voor key, een D voor door, en een E voor exit.
De gebruiker moet eerst de key pakken voordat je de door kunt openen.
